# 🌌 Overview

AI-IOS is a futuristic multi-agent AI platform that combines intelligent automation, immersive UI/UX, and AI-driven assistance into one unified ecosystem.

The goal of AI-IOS is to create a smart personal AI operating system capable of helping users manage studies, productivity, health, finance, planning, and digital life seamlessly.

# 🚀 Installation

## 📥 Clone Repository

```bash
git clone https://github.com/singhjesika/AI_IOS.git
cd AI_IOS
```

---

## 📦 Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Backend Server

```bash
uvicorn backend.main:app --reload
```

---

## 🌐 Run Frontend

Open:

```text
frontend/web/index.html
```

---

# 🔐 Environment Variables

Create a `.env` file and add:

```env
GROQ_API_KEY=your_api_key
OPENAI_API_KEY=your_api_key
```
